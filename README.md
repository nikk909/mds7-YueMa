## Project Overview

This MDS 7 project studies the trade-off between model accuracy and carbon emissions when training a deep MLP on Fashion-MNIST, tracked with CodeCarbon.

**Winning configuration:** Experiment C (100% data, 50 epochs) — Acc 89.74%, CO₂ 0.0007 g.
